# Keep selection snapshots inside their text area

Status: source implementation and scoped contracts complete; installed browser performance remains unverified. Upstream DSH `0.2.2-rc.1`, commit `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`.

The actual `.11` browser still fails the unchanged 80 ms reading budget: desktop 117 ms, mobile viewport 83 ms. A subsequent diagnostic records a 150 ms frame during the return-to-latest click. The Chat text-interaction document capture handler runs for that outside control and calls `document.getSelection()` before dismissing its local action. The full handler takes 55.1 ms, including 52.5 ms of style recalculation over 2,761 elements and 2.3 ms of layout. Later navigation and real new-row measurements occur in the same frame. CPU samples and nested native trace events establish this call path; the diagnostic is not another unprofiled acceptance result.

Take the previous-range snapshot only when the pointer target belongs to this text area's root. An outside pointer still dismisses its action, resets pointer selection and clears the current gesture-change flag. Retain the last observed range so an unchanged selection does not reopen the dismissed action. Selection itself is never cleared. Events inside the action surface, text-area pointer selection, keyboard selection and context menus retain their existing paths. No public contract, timer, layout estimate or reader ownership changes.

The regression mounts two real area hooks. An outside navigation pointer previously reads document selection twice; it now reads zero times while dismissing the action and retaining the selected text. A gesture in the first area reads once, then opens that area's action only after selection finishes. Existing tests cover outside dismissal, scroll/resize, Escape, cancellation, blur, context menus, keyboard selection and plugin removal. All 31 interaction/selection tests and their scoped types pass. These tests use jsdom geometry and do not establish browser frame improvement. Actual new-row measurement remains unchanged; the formal 117/83 ms failures remain open until a new installed candidate is measured.
