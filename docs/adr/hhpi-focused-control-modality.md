# Keep pointer focus-ring state on the focused control

Status: source contracts and package types passed; SDK build, installed consumption and browser performance remain separate. Package: `@deepseek-ai/dsh-client-ui-theme`, pinned DSH `0.2.2-rc.1`, upstream `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`.

The bounded `.16` desktop diagnosis (`b18521db-1c95-4bf4-be74-0531291666ae`) observed the first public input-modality change, absent to pointer, followed by 43.138ms of style recalculation affecting 2,842 elements. The actual theme sheet contains `html[data-input-modality='pointer'] body :focus-visible:not(:read-write)`. In the same diagnostic context, removing only that rule and repeating an absent-to-pointer change reduced the adjacent recalculations to zero or one element. This isolates the global focus selector; it does not establish an end-to-end speedup or an 80ms pass. The older trace also shows that same-value root attribute writes did not cause the whole-document work, so the public publisher needs no idempotency patch.

The dynamic theme now observes the existing public `data-input-modality` attribute and owns one private `data-dsh-pointer-focus` marker on the actual focused control. The CSS rule uses that local marker and `:focus-visible:not(:read-write)`, with no modality-dependent ancestor. A focus change transfers the marker; keyboard mode or plugin disposal removes it. Focus listeners run in capture so a control that consumes a bubbling focus event still receives the normal ring behavior. No layout read, focus movement, key cancellation or additional modality policy is introduced.

The primitive input-modality publisher remains the owner of pointer, navigation-key, IME and key-followed-by-focus rules. Editable controls keep their ring feedback; read-only controls keep pointer suppression. Ring color continues to inherit into descendants and pseudo-elements, while outlines, elevation shadows and selected borders retain their existing geometry. Documents without a window still mount their eight sheets without acquiring a focus observer. Disposal disconnects the observer and focus listeners and removes the owned marker without changing the public document modality.

This is one dynamic package consumption change. The static `ui-primitives` code embedded in `dsh-web-frontend` does not need rebuilding; the corresponding source-built cohort adds ui-theme as package 22. No HHPI wire, native execution, private preparation, spacer or viewport measurement changes are included. The observed room changes and restore/resize geometry chains still require their real measurements and remain a separate unresolved part of the reading path.
