# 源窗口架构重构验收（2026-10-28）

本轮把 HAPI 正文从 DSH 执行会话中分离。当前主路径为 HAPI 消息及游标 → 纯投影 → 独立正文流/历史页 → 单一客户端源窗口 → 官方 Conversation。历史改写保留执行 Agent、Session、队列、审批和输入归属。设计及后续修改规则见 [源窗口说明](source-view-architecture.md) 和 [AGENTS.md](../AGENTS.md)。

## 已完成

- 历史页不再创建临时 Session，也不经 Host 虚拟 seq/turn/step 映射。Host 返回带源身份的帧，客户端只在显示投影中分配数字坐标。
- Native、Observed 及两类子视图均使用独立 `SourceFrameFeed`。操作 Session 不再累积正文批次，慢订阅者只保留一个变化批次或当前基线标记。
- 客户端删除原 tail/display 双窗口及跨流持久坐标表。源重写、重连及 Host 重启通过正文版本与实例标识清理旧窗口；迟到分页、目录和附件读取不能恢复旧内容。
- 原 Session 的官方操作传输保持原语义。真实组合契约覆盖正文进入官方 Conversation，同时保留 pending、inbox、approval 和原生状态；首次发送后的等待状态由实际正文解除。
- AGENTS.md 已规定独立正文流、同 owner 改写、快速测试内循环和有界发布体验验证。

## 仍需区分的边界

当前完整 turn 为不可拆分保留项；一个超大 turn 仍可超过 Host 的常驻窗口预算。旧数字坐标 RPC 仅留作兼容，新正文和回退主路径使用源身份。上述浏览器检查验证已载入历史的滚动，没有证明跨页全档覆盖、长时间重连或长期可用性；这些路径已有针对性契约，但不能等同于真实生产长期验证。未在生产发送、取消或裁决审批，也未验证物理手机软键盘。此次结果不能直接推导与 HAPI 相同的可用性或性能倍数。
