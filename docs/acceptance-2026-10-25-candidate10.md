## 内存与尚未完成的验收

内存 SMOKE **未完成正常汇总，且已观察到超标**。计划为归档遍历后运行 60 秒；整个测试在 360 秒总上限超时退出，保留了 20 个样本、其中 3 个 GC 样本，以及归档覆盖记录。没有正常 `end/summary`，不能将它描述为完成的正式内存验收，也不延长时间后改写本轮结果。

| 指标 | 本次采样最大值 | 测试的工程回归上限 |
| --- | --- | --- |
| 显示 Host RSS | 329.45 MiB | 512 MiB |
| 显示 Host JS heap / external | 133.79 / 43.42 MiB | 256 / 64 MiB |

以上是短测已采到的最大值，不是连续峰值或平台稳定性结论。RSS 包含 JS heap，不能把各列相加；多个进程 RSS 合计也不是排除共享页后的物理内存。进程范围为本测试的一个 Host 与同一组 6 个 Chromium 进程，没有混入外部浏览器或 webshot。

归档读取收到了 5714 个投影事件、约 15.70 MiB 的实际窗口响应。180.7 秒遍历内，900 个计划正文标记中实际进入视口的有 679 个；已由源提供的 773 个中仍有 94 个没有视口证据。因此覆盖失败，不能把未看到的标记一概宣称为永久丢失。归档打开并 GC 后仍有 30148 个 DOM 节点，关闭后降到 4798 个。这确认了大历史打开期间的驻留压力，但没有证明长期泄漏。

本轮尚无 900 秒平台稳定性结果，也没有完成真实目标的 HAPI/DSH 配对 20 次缓存打开、5 次首次挂载和 5 次新浏览器测量。因此内存达标、缓存打开延迟、真实实时更新延迟及完整移动滚动体验均不能宣布通过。

此前报告的 Chrome 下拉刷新、布局冲突反复提示、队列编辑/投递、权限设置、跨刷新草稿恢复和安装包兼容性，本轮没有逐项重测。附件测试中的草稿保留不能替代跨刷新恢复；手机截图中布局正确也不能替代真实触摸惯性测试。它们不计入本轮通过项。
